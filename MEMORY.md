## 🔌 **OPÇÃO 1: QR CODE MANUAL (MAIS SIMPLES AGORA)** ⭐

Esta é a forma mais rápida para conectar seu WhatsApp pessoal agora mesmo!

### **Como funciona:**

```yaml
Fluxo completo:
  
  1. Você abre o navegador (Chrome/Edge/Firefox) no Windows
  2. Acessa: https://gateway.example.com/acesso/qr (ou link fornecido pelo OpenClaw)
  3. Aparece um QR Code na tela do navegador
  4. Escaneia com seu WhatsApp pessoal (celular)
  5. Agente Acessor começa monitorando automaticamente!

O que o agente saberá:
  ✅ Todas as mensagens pessoais (conversas 1-a-1)
  ✅ Todos os grupos (anúncios do bairro, família, trabalho, etc.)
  ✅ Status de leitura/livro
  ✅ Novas publicações em tempo real
  ✅ Membros que entram/saem dos grupos

Memória persistente:
  ✅ Histórico completo de todos os grupos monitorados
  ✅ Anúncios recentes com data/hora
  ✅ Busca inteligente em todas as mensagens
  ✅ Agendamento automático de posts (configurável)

Exemplo prático:
  Você pergunta ao agente: "Quem anunciou ontem uma TV?"
  
  Agente Acessor responde (baseado na memória):
    """=== ANÚNCIOS DE TVs (últimos 24h) ===
    
    [Ontem 18:30] - Grupo 'Anúncios do Bairro'
    Postado por: João Silva
    Conteúdo: "Vendo TV Samsung 55" Smart, estado novo, R$ 2.500"
    
    Status: Publicado | Leitura: 47 pessoas"""

Benefício: O agente funciona como um assistente virtual que sabe TUDO sobre seus grupos! ✅
```

## 🔄 **OPÇÃO 2: WHATSAPP CLOUD API (META) - MAIS ROBUSTO**

Para produção escalável (opcional, se quiser):

```yaml
Fluxo completo:
  
  1. Registrar número no Meta Cloud API Dashboard (meta.cloud.com)
  2. Configurar webhook URL para o Agente Acessor
  3. Escaneia QR Code via dashboard do Meta
  
Vantagens comparadas ao QR Code manual:
  ✅ Multi-dispositivo (roda no servidor, não no celular)
  ✅ Não precisa manter navegador aberto
  ✅ Histórico de mensagens completo
  ✅ Escalável para muitos grupos

Limitações:
  ⚠️ Requer número de WhatsApp Business separado (novo número)
  ⚠️ Configuração inicial via Meta Dashboard
```
