## 🔥 Ideias "Nunca Fazer" (Learned Lessons)

### ⚠️ Evitar no MVP:
1. **"Feature Creep"** - Não adicionar funcionalidades além do escopo definido
2. **"Personalização Excessiva"** - Cada cliente diferente = não escala
3. **"Integrações Complexas"** - Começar com API genérica antes de integrações específicas
4. **"Documentação em Segunda"** - Documentar junto com o desenvolvimento

### 💡 Lição do Acib (Experiência desde 1997):
> "O hardware mais barato muitas vezes compensa com arquitetura simples e eficiente."
> - Aplicável a SaaS: Infraestrutura otimizada > Features desnecessárias
