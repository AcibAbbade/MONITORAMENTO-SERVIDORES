# 📁 Estrutura Organizacional para Projetos

## 🎯 Filosofia
Organização exagerada = Clareza máxima. Cada projeto terá sua própria estrutura modular e independente.

---

## 📂 Estrutura Base de Projeto

```
[PROJETO]/
├── .git/                      # Controle de versão
├── README.md                  # Visão geral do projeto
├── CLIENTES/                  # Clientes e stakeholders
│   ├── 01-ativo/              # Clientes ativos atuais
│   │   ├── [nome-do-cliente]/
│   │   │   ├── contrato.txt   # Termos de contrato
│   │   │   ├── contato.md     # Pessoa de contato
│   │   │   └── notas.md       # Anotações importantes
│   │   └── ...
│   └── 02-arquivado/          # Clientes finalizados
│       └── ...
├── IDEIAS/                    # Brainstorm e insights
│   ├── 01-geral/              # Ideias gerais
│   ├── 02-projeto-específico/ # Ideias do projeto
│   │   ├── brainstorm.md
│   │   └── insights.md
│   └── 03-futuro/             # Roadmap e futuro
│       └── roadmap.md
├── PENDENCIAS/                # To-do e pendências
│   ├── 01-urgente/            # ⚠️ Prioridade alta
│   │   ├── [data]/           # Agrupado por data
│   │   └── ...
│   ├── 02-media/              # 📅 Prioridade média
│   │   └── ...
│   └── 03-baixa/              # 👉 Prioridade baixa
│       └── ...
├── ASSUNTOS/                  # Tópicos e temas
│   ├── 01-técnicos/           # Tecnologia, código, arquitetura
│   │   ├── [subtema]/        # Pastas específicas por subtema
│   │   └── ...
│   ├── 02-dominio/            # Área de atuação específica
│   │   └── [subtema]/
│   └── 03-operacionais/       # Processos, workflows, docs
├── RELATORIOS/                # Outputs e relatórios
│   ├── brutos/                # Dados crus não processados
│   ├── consolidados/          # Relatórios prontos
│   └── apresentacoes/         # Slides, decks
├── RECURSOS/                  # Assets e recursos
│   ├── documentos/            # PDFs, specs, manuais
│   ├── imagens/               # Imagens, logos, assets visuais
│   ├── codigos/               # Snippets reutilizáveis

├── ARQUIVOS/                  # Arquivos gerais não categorizados
│   └── [data]/                # Data no nome do arquivo
└── META/                      # Metadados do projeto
    ├── config.json            # Configurações específicas
    └── notas.md               # Observações gerais do projeto
```

## 🛠️ Guia de Uso

1. **Novo Projeto:** Copie a estrutura base, renomee pasta como `[NOME-PROJETO]`, atualize README.md
2. **Novo Cliente:** Crie `CLIENTES/01-ativo/[nome-do-cliente]/`, preencha README
3. **Nova Pendência:** Crie arquivo em `PENDENCIAS/[prioridade]/` com nome: `[DATA]_[descricao].md`
4. **Novo Tópico Técnico:** Crie pasta sob `ASSUNTOS/01-técnicos/[subtema]/`

---

## 🎨 Cores de Status (README.md)
- `🚧 Em andamento` - Projeto ativo
- `✅ Concluído` - Finalizado
- `⏸️ Paused` - Pausado temporalmente
- `🔴 Risco Alto` - Bloqueadores críticos
- `🟡 Risco Médio` - Atenção necessária
- `🟢 Risco Baixo` - Operando normalmente
